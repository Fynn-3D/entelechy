# Entelechy

Kernels (`.ent`) compute; scenes (`.esn`) compose them into a running world. Whole programs are in `examples/`.

## types: the types a port, a param or a value has

- **Rows**: `Rows<T>` A row of elements, element() the index of one; count(f) says how many, at(f, i) reads one.
- **Grid**: `Grid<T>` A grid of elements, coord() the column and row of one; size(f) and at(f, vec2) read it.
- **Volume**: `Volume<T>` A volume of elements, coord() the column, row and layer of one.
- **Image**: `Image` Grid<Vec4>: a picture, each channel a Float from 0 to 1, the first output that is one is what a scene shows.
- **Float**: `Float` A 32-bit float; written 1.0 or 2.5e-3, never 1.
- **Int**: `Int` A 32-bit integer; an overflow fails the element, add_wrap and its kin wrap.
- **Bool**: `Bool` true or false.
- **Double**: `Double` A 64-bit float; a literal is taken exact.
- **Long**: `Long` A 64-bit integer.
- **Vec2**: `Vec2   Vec3   Vec4` Floats in two, three or four components: v.x, v.y, v.z, v.w, and v.rgb, v.xy and the like as swizzles.
- **Vec3**: `Vec3` Three Floats; see Vec2.
- **Vec4**: `Vec4` Four Floats, a pixel's r g b a; see Vec2.
- **IVec2**: `IVec2   IVec3` Integers in two or three components: a cell, an offset, an address for at and put.
- **IVec3**: `IVec3` Three integers; see IVec2.
- **IVec4**: `IVec4` Four integers; see IVec2.
- **Mat2**: `Mat2   Mat3   Mat4` Float matrices by columns: m[i] a column, m * v applies it.
- **Mat3**: `Mat3` A 3 by 3 Float matrix; see Mat2.
- **Mat4**: `Mat4` A 4 by 4 Float matrix; see Mat2.
- **DVec2**: `DVec2   DVec3   DVec4` Doubles in two, three or four components.
- **DVec3**: `DVec3` Three Doubles.
- **DVec4**: `DVec4` Four Doubles.
- **LVec2**: `LVec2   LVec3` Longs in two or three components.
- **LVec3**: `LVec3` Three Longs.
- **DMat2**: `DMat2   DMat3   DMat4` Double matrices by columns.
- **DMat3**: `DMat3` A 3 by 3 Double matrix.
- **DMat4**: `DMat4` A 4 by 4 Double matrix.
- **as**: `input albedo: Grid<Vec4 as unorm8>;` How a port's Field is stored: f16, unorm8, snorm8, unorm16, u8, i8, u16, i16, or word; a Kernel reads and writes the type, the storage is narrower.

## kernel: how a Kernel is written: its declarations and expressions

- **requires**: `requires { field.read; field.write; time.read; input.read; }` The capabilities a Kernel uses, and no others: reading inputs, writing outputs, the clock, the pointer, keys and window.
- **input**: `input x: Image;   = "atlas.png";   = text "ENTELECHY";   = frames "clip/" at 30;` In a Kernel, a Field it reads, bound by the node that runs it (`source <- other.result;`); in a scene, a Field the caller supplies, or one the Host reads from a file, from text, frame by frame from a directory, every file under a directory with its path, or what the language finds wrong in, or defined by, a file's or a directory's documents, as text; or one a Host device feeds, named after `=` (`= clipboard`, `= progress`), refused as the scene loads when the Host has no such device or it gives another type.
- **param**: `param gain: Float = 1.0;` In a Kernel, a value the node that runs it may set (`gain = 0.5;`), with its default; in a scene, a value the caller sets (`--param`, the protocol's `param`) and its nodes read by name.
- **output**: `output result: Grid<Vec4>;   output shown <- node.port;   output kept <- node.port to "saves/n.field";` In a Kernel, a Field it writes, an element per element of its domain (a map may write several); in a scene, a named result: the first picture given no device is what it shows; one given `to` a Host device by its name goes there (`to sound`, a block of samples each frame joined to the last, `rate()` over the frame rate keeping it in time; `to pointer`, `to pointer_tip`, `to clipboard`; a name the Host has not, or a Field of another structure, is refused with what the device takes); one written `to` a file is saved after each evaluation that changed it, where allowed; one written `to files` a directory is a list of operations on its files (write, remove, rename), done once each time it changes.
- **type**: `type Cells = Grid<Int>;   struct Cell { alive: Int; age: Float; }` A name for a port type, an enum, or a struct of named fields, shared by the Kernels of a document.
- **enum**: `type Mode = enum { Idle, Walk, Attack = 10, Guard };   Mode.Walk   match m { Mode.Idle => a, Mode.Walk | Mode.Attack | Mode.Guard => b }` Named Ints: a variant is the number written after it, else one past the variant before it, the first 0, so `Mode.Guard` is 11; no two are one number. `Mode` is a type a value, a field, a port's element and a parameter may have, and a scene writes a variant where it writes a number. A variant whose number is kept in state, a memory or a file, is written with its number, so no variant written before it moves it.
- **let**: `let name = expr;   let { x, y: top } = value;` A binding, immutable and scoped to its block; `let _ = put(...)` is a statement for its effect. A `{ ... }` names fields of one value instead, each under its own name or the one written after `:`.
- **if**: `if condition { a } else { b }   if condition { return a; }` Both arms give one type and only the arm taken runs, which a trace shows; with no `else`, among a block's statements, it guards, and the rest of the block is its other arm.
- **operators**: `a + b   a - b   a * b   a / b   a % b   a << b   a >> b   a >>> b   a & b   a ^ b   a | b   a == b   a != b   a < b   a <= b   a > b   a >= b` Arithmetic on numbers and, component by component, vectors, `/` and `%` on Ints truncating toward zero; on Ints only, `<<`, `>>` keeping the sign, `>>>` filling with zeros, and `&`, `^`, `|` bit by bit; a comparison gives a Bool. From the tightest: unary `-` and `!`; `*` `/` `%`; `+` `-`; the shifts; `&`; `^`; `|`; the comparisons; `&&`; `||`.
- **and**: `a && b   a || b   !a` Truth: `&&` and `||` ask the other side only where the first settles nothing, so a guard guards and what it guards does not run.
- **match**: `match i { 0 => a, 1 | 2 => b, 8..16 => c, 16..=31 => d, _ => e }` On an Int: the arm whose values hold it, else the `_` arm, which comes last; arms naming every variant of an enum need none, and a value that is no variant takes the last arm. The GPU runs it as a switch. A range is the values it holds, `..` stopping before its end and `..=` taking it, at most 256 to an arm.
- **loop**: `loop n with x = init until done { next }` A bounded fold: `n` is a literal, which is its bound (at most 65536), or any Int expression read once and run whole, the element's budget its bound; `index()` is the iteration, and `until` stops it early, as `break` does from inside.
- **break**: `loop n with x = init { if done { break x; } next }` Among a loop body's statements: the loop stops after this iteration and gives that value, which is of the type it carries; the iterations after it do not run, and a `break` belongs to the innermost loop around it.
- **each**: `[each n { body }]` An array built element by element, the body run once per element with `index()` its position; a loop inside the body has its own `index()`.
- **array**: `[a, b, c]   [value; n]   a[i]` A fixed-size array of one element type, or `n` copies of a value; `a[i]` takes an element, clamped, and a literal index is checked when compiled.
- **struct**: `Name { a: 1.0, b: 2 }   Name { ..base, a: 3.0 }` A value of a declared struct, or a copy of one with some fields replaced.
- **fn**: `fn name(a: Float) -> Float { ... }   fn name<T>(a: T) -> T { ... }` A function of the document or the Kernel; a call reaches the Kernel's own, then the document's own, or else the one a document it uses declares; it calls others in any order, but no chain of calls comes back to it, and it may take a Field parameter. A `<T>` names a type parameter, bound by the type of the argument written for it, and one instance is compiled per set of types a call gives it.
- **kernel**: `kernel id@version { requires { ... } input ... output ... compute { ... } }` A Kernel: what it needs, its ports and parameters, and one of `compute`, `scan`, `scatter`, `prefix` or `group`.
- **budget**: `budget 100000;` The loop iterations one element may run (a step of a scan, a merge of a reduction), 16777216 unless declared, a loop's added as it finishes; an element past it fails the evaluation on every backend, as an overflow does, and the running system keeps its last state. A run of all the elements together is bounded by the Host (`--work`).
- **compute**: `compute { return value; }` The map mode: the body runs once per element of the node's domain and gives that element.
- **merge**: `compute over source { ... } merge(a, b) { ... }` The reduce mode: `compute` runs per element of the input it names after `over` and `merge` folds the results pairwise into one element; the output may be written as its element type.
- **scan**: `scan over ticks with y = init { return next; }` The ordered mode: one element per element of the input it names after `over`, in order, carrying `y` from the step before; `memory` ports are read and written step by step.
- **prefix**: `prefix over flags with sum { return value; }` The prefix mode: the body runs once per element of the input it names after `over`, a `Rows`, and that element of the output is its value combined with every value before it by `sum`, `min` or `max`. The rule must give one answer whatever order it is folded in, so a float `sum` is refused (a `scan` walks that in element order) and a device folds the row in blocks rather than walking it.
- **scatter**: `scatter over source into target with sum { return Pair { at: address, value: v }; }` The scatter mode: the body runs once per element of the node's domain, which has the shape of the input it names after `over` (`element()` and `coord()` read it), and gives a struct the document declares, of two fields, an address into the target and a value of its element (`struct Pair { at: Int; value: Float; }`); the value is combined into the target at the address with `sum`, `min`, `max` or `last`, in element order.
- **group**: `group 64 { let mine = f(element()); return exchange(mine, lane() ^ 1); }` The group mode: a map whose elements run in groups of the size written (1 to 256), element e lane e % size of group e / size, the lanes of a group meeting at each `exchange`. The last group runs whole past the domain's end, its lanes there giving at exchanges, failing as any element fails, and writing nothing.
- **memory**: `memory ram: Rows<Int>;   put(ram, address, value)` A port an ordered Kernel both reads and writes, step by step; it comes out as an output.
- **reserved**: `let return if else match loop with until break` The words the language keeps for itself, each beginning a statement or an expression or going between its parts: a Kernel, node, port, param, function, struct or binding may not be named one. The words that begin items (`kernel`, `input`, `type`, `from` and the rest) name things anywhere else; a Kernel's param is not named `domain` or `async`, which a node sets itself.

## scene: how a scene is written: nodes, bindings, inputs and packages

- **node**: `node name: fx.glow@1 { port <- source.result; param = 2; domain = vec2(w, h); }` A node runs a Kernel: its inputs wired at the consumer, its parameters set, its extent explicit or the first input's.
- **inline**: `node name: kernel { ... input x: Image <- src; ... }` A Kernel written in place; its inputs carry their wiring, `<-` or `<~` with its initial source (`input s: Rows<Float> <~ name.result from start.result;`), a param whose default names a scene param follows that param (`param gain: Float = amount;`), and the session publishes it under the document's name.
- **fill**: `node zeros: Rows<Float> { domain = 65; value = 0.5; }` A node that is a Field rather than a Kernel: its element's zero, or the `value` given, over the domain. Its element is a Float, Int, Bool, Vec2, Vec3 or Vec4 (a pixel for `Image`), or an alias of one; a struct is filled by a Kernel.
- **graph**: `node name: graph "other.esn" { source <- src; param = 2; }` Another document placed as a node: its nodes join under `name.`, its inputs take the wiring, its outputs are read as `name.output`.
- **font**: `node g: font "fonts/x.ttf" { codes <- wanted.result; }` A font file's glyphs as the Host reads them, for the characters `codes` (a `Rows<Int>` of code points) held when last evaluated, so a frame later: `g.glyphs` a row a code in order (`code: Int; advance: Int; first: Int; count: Int; lo: Vec2; hi: Vec2`, the advance in the font's units, the box in ems; a code the font lacks -1), `g.outlines` their outlines' line segments in ems, y up (`Rows<Vec4>`), `g.metrics` one row (`units: Int; ascent: Float; descent: Float; gap: Float`). Read again when `codes` or the file changes.
- **previous**: `port <~ node.output from initial [migrate id@v];` State: the port reads what the last evaluation committed, the initial source before the first, and a migration carries it when a republished Kernel changes its layout; the Kernels reading the port are republished for the new layout with it.
- **times**: `times = 5;   carry port <- output;` A node written once and placed N times, each wired as written, `carry` feeding a port from the previous time's output; at N = 0, a carried output is what its port is first bound to.
- **async**: `async = true;` The node runs off the frame: the evaluation starts it on a thread and goes on, its readers taking the last output until the run lands.
- **require**: `require cells: columns * rows <= 1 << bits;` What the scene's parameters must hold to run: two counts over its params, numbers, `window()` and `scale()`, compared. It is checked as the scene loads (`check` and `compose` refuse one the given params break) and before every evaluation, which stops before anything runs; each says what the sides came to. A placed graph's come with it, under its node's name.
- **use**: `use "kernels/";   use "name.entpkg";` The documents whose Kernels and declarations this one brings in: a file, a directory, or a package; what those use in turn is theirs.
- **package**: `package name@1 { language = 1; ir = 1; }` The manifest of a package directory: what it is called and the least language and IR it needs.
- **qualified**: `let n = random::fbm2(p);   let m = ui_panel::Mark { b: 1 };   input marks: Rows<ui_panel::Mark>;` A name a used package declares, written with the package's name before it: the one declaration of that name in that package. Two packages a document uses may declare one name; the document names each by its package. A name declared or bound here is a plain word.
- **vec2**: `vec2(w, h)` A grid's extent.
- **vec3**: `vec3(w, h, d)` A volume's extent.
- **count**: `count(port)` How many elements an input port of this node holds.
- **size**: `size(port)` An input port's extent: a count, a pair or a triple.
- **value**: `value(port)   value(port, i)` A number a Kernel wrote: element i (0 when not given) of an input port of this node, read as the node binds.
- **window**: `window()` The window's size in pixels; the node runs again at the new extent when it changes.
- **scale**: `scale()` The window's pixels per logical pixel.
- **max**: `max(a, b)` The larger, componentwise.
- **min**: `min(a, b)` The smaller, componentwise.
- **floor**: `floor(x)` A measure made whole, rounding down.
- **ceil**: `ceil(x)` A measure made whole, rounding up.

## authority: the capabilities a Kernel declares in `requires`

- **field.read**: `field.read` Read the elements and extents of the Fields bound to its inputs, images included.
- **field.write**: `field.write` Create and write its output Fields, images included.
- **time.read**: `time.read` Read the session clock and the sound rate.
- **input.read**: `input.read` Read the pointer, buttons, keys, pad and wheel, and the window's pixel size and scale.

## packages: what a package holds and how a scene reaches one

- **manifest**: `name.entpkg/package.esn: package name@1 { language = 1; ir = 1; }` Its name and edition, and the least language and IR it needs: one this Entelechy does not have refuses the package, naming both. The directory is named for the package, `name.entpkg`; a scene reaches one package of a name, and two, as two editions of one, are refused.
- **kernels**: `use "kernels/";   (in the manifest)` The documents the manifest uses, inside the directory, are the package's Kernels; a scene that uses the package publishes every one of them. A document outside the package uses it whole, never a file inside it, so the manifest's versions hold.
- **graphs**: `name.entpkg/graphs/*.esn` Preset graphs, placed with `node n: graph "name.entpkg/graphs/g.esn" { ... }`.
- **docs**: `//! at the top of a manifest or a preset;   /// above a Kernel, a port or a param` What each part is for, in its source; `kernel` and `kernels` answer a published Kernel's.
- **assets**: `name.entpkg/font.png` Any other file in the directory, which a scene's `input` reads by its path or through the package's name (`name.entpkg/font.png`), as a document is; a package's files are readable wherever reads are held.
- **by name**: `use "name.entpkg";` A package not beside the document is found by its name: beside the package the document is in, so packages kept together name one another; then in each directory of `ENTELECHY_PACKAGES`; then in `packages/` beside the program. Among files handed in (a page), in `packages/` among them.

## protocol: the operations a session answers

- **status**: `status` {} The session at a glance. Answers backend, scene, watched, kernels (published Kernels), natives (the backend's native operations), nodes, loaded (whether a scene is), refused (why not, when not), revision (moved by every change but running), frame (the frames committed since that revision), fusion, grants, memory (`used` and `budget`, the Host's bytes; `cold`, the nodes whose outputs are let go, made again when read; where the bytes are: `host`, `device`, `kept` (resident Fields' Host copies), `spare`, `loose` (Fields nothing holds), `backends` (what each keeps of its own) and `top`, the largest Fields with what holds each), versions (`entelechy`, `api`, `language`, `ir`, `package`).
- **kernels**: `kernels` {} Every published Kernel, with its generation. Answers a list of manifests, each with its generation, which `publish`'s `expect` names.
- **kernel**: `kernel` {`kernel`?: string, `generation`?: integer} One Kernel's manifest and source. Answers manifest, generation, source, as `publish` takes it.
- **graph**: `graph` {} The running scene's structure. Answers inputs, params, nodes, outputs (each with its `source`, and `to`: the Host device it is given to, or null), fonts (each font node: id, path, codes, its outputs and the inputs they are in), files (each files node: id, path, paths, its outputs and the inputs they are in), fields (each fields node: id, type, path, paths, its outputs and the inputs they are in).
- **document**: `document` {`version`?: string, `path`?: string} The scene document's text, or another document of the scene's. Answers path, text, and version, which `compose`'s `expect` names.
- **history**: `history` {`since`?: integer} What changed the world, and what was refused. Answers revision, frame (the frames committed since that revision), the changes after `since` and the attempts refused since, each with its origin.
- **compose**: `compose` {`text`?: string, `edits`?: [{node?: string, output?: string, param?: string, require?: string, input?: string, kernel?: string, struct?: string, type?: string, fn?: string, use?: string, member?: string, text: string | null}], `expect`?: string, `path`?: string, `documents`?: [{path?: string, text?: string, edits?: [{node?: string, output?: string, param?: string, require?: string, input?: string, kernel?: string, struct?: string, type?: string, fn?: string, use?: string, member?: string, text: string | null}], expect?: string}]} Changes the scene: rewrites its document on disk (`document` and `status` name it), or with `path` or `documents` the scene's other documents too, once the texts are checked; answered once the scene stands. A refused text writes nothing and is an error: why, at `line` and `column`, the document's `version`, and for `edits` the `text` they made, which `line` counts in. Answers events, version, path (the scene), written; with `path` or `documents`, documents (each written document's path and version).
- **sync**: `sync` {} Reads every changed document again. Answers events.
- **prepare**: `prepare` {`source`: string} Compiles a Kernel and says what is wrong with it; publishes nothing. Answers id, manifest; or an error at a line and column.
- **publish**: `publish` {`source`: string, `expect`?: "absent" | "any" | integer} Compiles, validates and prepares a Kernel, then swaps it in whole; answered once it stands. The running world changes, not a file: the document it came from is left as it is. Answers id, generation; and when it computes a `<~` port's initial source, `keeps` (those `node.port`s, which keep what they committed) and `reset` (the requests that start them from the new law).
- **retire**: `retire` {`kernel`?: string} Removes a published Kernel. Answers retired.
- **param**: `param` {`name`: string, `value`: value} Sets a parameter the scene declares. Answers name, value, events; a node's own value is refused, and changes by `compose`.
- **evaluate**: `evaluate` {`nodes`?: [string], `settle`?: bool, `measure`?: bool, `clock`?: bool, `time`?: number, `rate`?: number, `queued`?: number, `pointer`?: [x, y], `down`?: bool, `buttons`?: [integer], `wheel`?: [x, y], `sticks`?: [[x, y]], `pads`?: integer, `keys`?: [integer], `text`?: string, `window`?: [w, h], `scale`?: number} Runs one frame. Answers executed, reused, committed, outputs, timings, measured, device, let_go (nodes let go to make room in the Host); in the Player, ignored (the context fields it gave, which the window's own input stands in for) and a note.
- **warp**: `warp` {`steps`: integer, `dt`?: number, `nodes`?: [string], `until`?: string, `settle`?: bool, `time`?: number, `rate`?: number, `queued`?: number, `pointer`?: [x, y], `down`?: bool, `buttons`?: [integer], `wheel`?: [x, y], `sticks`?: [[x, y]], `pads`?: integer, `keys`?: [integer], `text`?: string, `window`?: [w, h], `scale`?: number} Steps causal state forward across many ticks without evaluating unasked outputs, stopping early when `until` becomes non-zero or non-finite, or once a clockless scene settles. Answers steps (ticks run), active (ticks that advanced state), time (causal seconds of the last tick), millis, stopped (`"steps"` | `"until"` | `"settled"` | `"nonfinite"`), until (when `until` was given), executed, reused, committed, let_go.
- **read**: `read` {`output`?: string, `node`?: string, `port`?: string, `format`?: "png" | "rgba32f" | "ppm" | "summary" | "words" | "field", `from`?: integer, `count`?: integer} Reads an output or a node's port. Answers a picture: width, height, format, data (base64). Any other Field: shape, extent, count, schema, `fields` (each number's name in an element of several, `hp`, `pos.x`), and its summary (each number's min, max, min_at, max_at, sum, mean, rms, how many were not zero, and when any were not finite: nonfinite, nan, inf, first_nonfinite), or `values` from `from` (a number, or a list for an element of several), or format and data (base64).
- **write**: `write` {`node`: string, `port`?: string, `data`: string, `format`?: "words" | "field"} Replaces a node's committed state. Answers the state replaced.
- **snapshot**: `snapshot` {`to`?: string} The whole world: its Kernels, its scene and every committed state. Answers the world's revision and frame (the frames committed since it), every Kernel with its generation and source, every port's committed state; or the file written.
- **restore**: `restore` {`snapshot`?: object, `from`?: string, `laws`: "current" | "snapshot", `structure`?: "current" | "snapshot", `time`?: number, `rate`?: number, `queued`?: number, `pointer`?: [x, y], `down`?: bool, `buttons`?: [integer], `wheel`?: [x, y], `sticks`?: [[x, y]], `pads`?: integer, `keys`?: [integer], `text`?: string, `window`?: [w, h], `scale`?: number} Puts a snapshot's world back, after a trial frame that commits nothing: the state is the snapshot's, which the next frame reads; until then `read` shows the trial frame's outputs. Answers revision, frame, report.
- **pause**: `pause` {`paused`?: bool, `step`?: integer} Holds a window's scene time still, lets it run, or steps it a frame (F8, F9 and F7 in the window). Answers paused, time (the scene's, in seconds); refused where the caller gives the time (`serve`: `evaluate`'s `time`).
- **reset**: `reset` {`node`?: string, `port`?: string} Forgets committed state; `<~` readers start from their initial sources. Answers what was reset.
- **help**: `help` {`name`?: string} Entelechy's syntax and API, layer by layer: all of it, or one name in full. Answers `reference`, the whole of it as one Markdown text, and `versions`; or with `name`, every item of that name in full. An unknown name is an error with `similar`.
- **trace**: `trace` {`node`: string, `at`?: [x] | [x, y] | [x, y, z], `element`?: integer, `time`?: number, `rate`?: number, `queued`?: number, `pointer`?: [x, y], `down`?: bool, `buttons`?: [integer], `wheel`?: [x, y], `sticks`?: [[x, y]], `pads`?: integer, `keys`?: [integer], `text`?: string, `window`?: [w, h], `scale`?: number} Runs one element of a node's Kernel and shows every step of it; with no context fields, under the last frame's context. Answers kernel, at, bindings, results, calls, and when the element failed, fault: its message, the function it failed in with that function's bindings, and the operation's path, line and column.
- **pin**: `pin` {`node`: string} Keeps a node materialized so `read` can see it. Answers pinned.
- **unpin**: `unpin` {`node`: string} Lets fusion have a pinned node back. Answers unpinned.
- **quit**: `quit` {} Ends the connection, or on standard input the process. Answers bye.

## wire: a request and an answer as they cross a door, and the doors

- **op**: `request: `op`: string` The operation: one of the protocol section's, each with its own fields.
- **id**: `request: `id`: value` Anything; the answer carries it back as it was sent, to pair them.
- **id**: `answer: `id`: value` The request's `id`, or null when it sent none or was not JSON.
- **ok**: `answer: `ok`: object` What the operation answered, as its entry in the protocol section says.
- **error**: `answer: `error`: object` Why the request was refused, and what acts on it as data; the world is as it was.
- **message**: `error: `message`: string` Why, one or more sentences for a person or an agent to read.
- **line**: `error: `line`: integer` Where the fault is, from 1: in the text the request carried, or in `path`.
- **column**: `error: `column`: integer` Where on that line, from 1.
- **similar**: `error: `similar`: [string]` The names nearest an unknown one.
- **fix**: `error: `fix`: object` The change that mends the fault, when one does: an item of `compose`'s `documents` that takes its document's place, handed back as it is; `path` with `text`, the refused change's own document with a `use` item added, or with `edits` adding it to the document on disk. A `rejected` event carries it too.
- **fields**: `error: `fields`: [string]` The fields the operation takes.
- **field**: `error: `field`: string` The field at fault.
- **expected**: `error: `expected`: string` The type that field is.
- **operations**: `error: `operations`: [string]` Every operation, for an unknown one.
- **version**: `error: `version`: string` The scene document's version as it stands, for a compose refused.
- **path**: `error: `path`: string` The scene document a refused compose would have written, or the document a failed element's operation is written in.
- **written**: `error: `written`: bool` Whether a compose wrote its document: false when refused.
- **text**: `error: `text`: string` The document an `edits` compose made, which `line` counts in.
- **node**: `error: `node`: string` The node an evaluation failed at.
- **port**: `error: `port`: string` The state port whose migration failed.
- **migration**: `error: `migration`: string` The Kernel that failed to migrate that state.
- **frame**: `error: `frame`: integer` The frame a run failed at, counted from its first.
- **stdin**: `entelechy serve <scene.esn>` Request lines on standard input, answer lines on standard output; `quit` ends the process.
- **socket**: `entelechy serve <scene.esn> --listen <host:port>` The same lines over each TCP connection to the address; `quit` ends the connection.
- **websocket**: `entelechy serve <scene.esn> --listen <host:port>` The same lines as WebSocket text messages to the same address, one request a message.

## replay: the lines of a replay test

- **scene**: `scene <path>` the scene to test, relative to the replay file; required
- **library**: `library <path>` Kernels beyond the scene's `use`
- **allow**: `allow file.write <dir> | allow file.delete <dir>` lets the scene's outputs write (or remove and rename) files under the directory, relative to the replay file, as `--allow` does; what they write is kept for the run and never reaches the disk, so every run starts from the same files; with or without it, what the scene saved for itself before the run (an output's file an input reads, with a fallback) is not read until the run writes it
- **alike**: `alike` its checks hold two forms of one computation equal word for word, which they are only where every Kernel rounds alike, so `--round-apart` leaves the replay out
- **frame**: `frame <seconds> [to <seconds> every <seconds>]` evaluates one frame at this session time; with `to` and `every`, a frame at each step from the first time to the last, both included
- **settle**: `settle` waits for every `async` run to land
- **pointer**: `pointer [<x> <y>] [down | up]` moves the pointer, in the output's pixels from its top left (what `pointer()` reads), and presses or releases it
- **button**: `button <name> down | up` left, right, middle, or a pad's south, east, west, north, l1, r1, l3, r3, start, select
- **stick**: `stick left | right | triggers <x> <y>` a pad's axis pair
- **pads**: `pads <count>` how many pads are connected from here on, what `pads()` reads
- **wheel**: `wheel <x> <y>` the scroll for the next frame only
- **window**: `window <w> <h> [<scale>]` the window in pixels, for `window()`, and its scale factor; one when not given
- **type**: `type "<text>"` characters typed, what `typed()` reads on the next frame (32 a frame, the rest on the frames after); `\"`, `\\`, `\n` and `\t` inside the quotes, `#` among them no comment
- **clipboard**: `clipboard "<text>"` the clipboard holding this text from here on, as a person copying elsewhere leaves it: what an input `= clipboard` reads; the same escapes as `type`
- **key**: `key <code> down | up` a key by the browser's code, as `key()` reads it: letters and digits by uppercase ASCII, space 32, enter 13, arrows 37 to 40, the rest in `help key`
- **reset**: `reset [<node.port>]` forgets every node's committed state, or one port's
- **param**: `param <name> <literal>` sets a graph parameter
- **expect**: `expect <x> <y> = <r> <g> <b> [<tolerance>]` the picture's color at x y from its top left, each channel 0 to 1 as the Kernel wrote it; tolerance 0.01 when not given
- **expect**: `expect <node.port[i][.field]> = <value>... [<tolerance>]` an element of a node's output, or a field of it (a struct's element is compared a field at a time; an array's element is named by its index, `.cells.2`): ints and bools exactly, floats and vectors within the tolerance; `i` counts along the Field, x fastest, then y, then z
- **expect**: `expect <node.port[i][.field]> < | <= | > | >= <number>...` every component of it past a bound
- **expect**: `expect count <node.port> = <n>` how many elements a node's output holds
- **expect**: `expect placed <node> main | ordered` where a node runs: the session's main backend, or ordered work off it; a session with one backend reads both as main
- **show**: `show <node.port[i][.field]>` prints an element of a node's output after the last frame, or a field of it, a struct field by field; it checks nothing, and the run reports what it shows
